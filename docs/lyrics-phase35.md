## 2. 변경 내용
- `providers/musicbrainz.ts`: 아티스트 검색(`searchArtists`, mbid·국가·구분정보·별칭), 아티스트별 녹음 목록(`browseRecordings`, 100개 단위 페이지, 크레딧에 없는 녹음 제외), 요청 간격(`minGapMs`, 앱은 1000ms), 캐시. `lookup` 은 제목 검색으로 못 찾았고 입력이 원어/로마자이면 곡 목록 첫 페이지에서 제목·별칭이 **정확히 같은** 곡의 표기를 가져온다. 한글 제목은 번역하지 않는다.
- `searchPlan.ts`: 가수가 있고 아직 못 찾았으면 한글이 없어도 MusicBrainz 조회 시도(로마자 제목 대응). 자유 검색(q)은 기존 조건 유지. 총 요청 상한 14회 그대로.
- `catalog.ts`(신규): 곡 목록 중복·버전(라이브/리믹스 등) 묶기, 제목 필터(원어/로마자).
- `aliasSeed.ts`: 가수 표기 묶음 6개 추가(Vaundy, Yorushika, Fujii Kaze, RADWIMPS, Mrs. GREEN APPLE, ONE OK ROCK). 곡 제목 하드코딩 없음.
- `useAutoLyrics.ts`: `searchForRecording`(선택한 곡으로 LRCLIB 재검색, 자동 선택 없음).
- `ArtistSongBrowser.tsx`(신규) + `AutoLyricsBar.tsx`: "가수별 곡 찾기" — 가수 검색 → 가수 선택(동명이인 구분 정보 표시) → 곡 목록(원어+로마자, 길이, 버전 묶음, 제목 필터, 더 불러오기) → 곡 선택 → 가사 후보 → 미리보기 → 적용(기존 흐름, 일본어 발음 자동 생성 포함).
- 안내: "MusicBrainz에 등록된 곡만 보여요. 전체 디스코그래피를 보장하지 않아요."

## 3. 안전 원칙
- 한글 제목 ↔ 원어 제목은 자동으로 이어 붙이지 않는다. 사용자가 목록에서 고른 것만 명시적 선택으로 간주한다.
- MusicBrainz 가 알려 준 별칭/제목만 사용(번역·소리 변환으로 만든 값 없음). 다른 가수의 같은 제목 곡은 가수 불일치로 제외.
- DB/스키마/Repository 변경 없음. 새 유료 API 없음.

## 4. 한계
- 실제 LRCLIB/MusicBrainz 응답은 샌드박스에서 차단되어 **실제 검증하지 못했다(BLOCKED)**. `npx tsx tests/manual/real-api-check.ts` 를 인터넷이 되는 PC 에서 실행해 결과를 확인해야 한다.
- MusicBrainz 에 한글 가수명/별칭이 없으면 한글 이름만으로는 가수를 못 찾는다(시드 사전 또는 원어/영문으로 검색).
- 곡 목록은 MusicBrainz 에 등록된 범위이고 아티스트당 첫 페이지(100개)부터 순차로 불러온다.
- MusicBrainz 는 초당 1회 이내 사용을 요청한다 — 앱은 요청 사이 1초 간격을 둔다(첫 가수 곡 목록 조회는 1~3초 걸릴 수 있음).
